# BrainBoost Quiz

Diese App ist eine Quiz-App mit den Kategorien Allgemeinwissen, Mathe und Englisch.

# Was macht die App?

Die Nutzer können eine Kategorie auswählen, Quizfragen beantworten und am Ende ihre Punkte sowie eine Auswertung sehen.

# Voraussetzungen

- Python
- pip

# App starten

pip install -r requirements.txt

python app.py

Dann im Browser öffnen:

http://localhost:8080
